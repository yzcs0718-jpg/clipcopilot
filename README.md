# ClipPilot · 个人视频工作台

**公开网站：https://yzcs0718-jpg.github.io/clipcopilot/**

多素材混剪、参考视频拉片与剪映复现教学。公开版可在浏览器运行免费开源模型，不需安装软件、填写 API Key 或调用付费推理 API。分析结果包含实测证据、复现候选和未确定项，不能承诺任意视频所有效果的准确识别或原工程还原。

## 使用

1. **剪辑创作**：导入一个或多个视频，生成规则混剪初稿，修改片段与自己的文案，预览并导出 MP4。默认不添加无关字幕。
2. **剪映拉片**：导入参考片后自动抽帧。点击 **深度拉片**，顺序运行画面文字、窗口几何、人物分割与文字/目标同动分析。首次需要下载免费运行组件和模型，视频采样留在当前浏览器。
3. **复现教学**：展开整片清单中的证据与时间点，核对原片。点击某项的 **生成本项教学 MP4**，生成针对这条线索的参考帧和字幕步骤视频。

没有素材可点 **测试中文花字与圆形窗口** 或 **测试单帧闪白**。人物模型另有独立自检，结果不会冒充上传视频的分析。

## 当前能力

| 功能 | 实现范围 |
| --- | --- |
| 多素材剪辑 | 可编辑片段、排序、预览、字幕、实际 MP4 下载、方案/SRT 与草稿 |
| 基础拉片 | 候选分段、前后帧、淡入淡出、短白闪、整体缩放、静止区间的像素线索 |
| 中文花字 | PaddleOCR 文字检测与识别，颜色采样、位置/尺寸变化；描边/阴影线索需对照，不能识别任意字体或特效预设 |
| 蒙版复现 | 圆形纹理窗口候选的中心和尺寸；不能区分所有实景圆形物体或识别任意形状蒙版 |
| 人物抠像复现 | 独立人脸校验后生成新的人物前景遮罩，可下载 PNG 并参考剪映智能抠像；不证明原片做过抠像 |
| 跟随复现 | 测量文字与非文字局部特征同动，过滤自匹配和近似整体平移，给出采样位置与关键帧建议；不证明用了自动跟踪 |
| 音轨 | 可选开源声音分类、Whisper 转录；原声、后加音效与具体音效库仍需听辨 |
| 教学视频 | 按实测线索生成参考帧和操作步骤 MP4；**不是剪映实机录屏** |
| GitHub Skills | 读取公开 SKILL.md、来源记录与参数预设；不执行第三方仓库脚本 |
| 提供商接口 | 智谱、Kimi、DeepSeek、豆包配置预设保留，远程付费模型调用保持关闭 |

### 检查范围与限制

- 视频最长 10 分钟；精细扫描目标约 24fps，最多 3600 帧，长片降低密度并显示实际间隔。可停止重扫并保留上次完整结果。
- OCR 最多 240 个时间点，候选分段边界附近加密。花字、遮挡、透视、小字和短动画可能漏掉或识别错。
- 空间分析最多 90 帧，长视频采样稀疏，跟随关系可能无法判断。
- 当前人物遮罩要求可见脸部并通过校验；背影、遮脸、远景、多人、精细头发以及非人物主体不保证可用。
- 成片无法唯一反推出原字体、插件、LUT、变速曲线、蒙版、抠像参数或隐藏背景。同动、圆形边界和人物分割本身都不是原编辑方法的证明。
- 作品链接只记录来源，不会自动同步整账号或批量下载平台视频。

## 验证记录

本轮 119 项 JS 回归测试通过，测试数不代表识别准确率。实际 Chrome 测试包含：

- 同一中文字图：此前 Tesseract 失败，现 PaddleOCR 正确读出“剪辑节奏”和英文。
- 原创 6 秒 MP4：六个采样点正确读出描边、彩色、阴影样式下的同一中文文案，获得移动轨迹。
- 同片圆形窗口：实测中心约 81%/58%、直径约占宽 22%；与生成参数接近。
- 同片找到 0.50–5.50 秒文字与独立局部特征的同动候选；加入独立校验后，几何负例不再生成“人物”遮罩。
- 官方公开肖像独立自检生成实际人物遮罩；不作为任意视频抠像准确率证明。
- 单帧白闪：6fps 扫描漏检，24fps 扫描捕获，时间括区约 1.04–1.13 秒。
- 单项圆形窗口教学实际导出、独立解码：17 秒、960×540 MP4。当前测试浏览器编码为 VP9，没有音轨，不代表所有剪辑软件都支持该编码。

## GitHub Pages 部署

本仓库已使用 `.github/workflows/pages.yml`：先运行 `npm test`，再发布 `dist/`。在自己的仓库使用时：

1. 上传完整源码，保留目录结构。
2. Settings → Pages → Source 选择 **GitHub Actions**。
3. 提交到 main，等待 workflow 成功后访问返回的网址。

不要上传密钥、个人视频、QA 截图、模型缓存或 `.openai` 配置。最新源码：https://github.com/yzcs0718-jpg/clipcopilot/archive/refs/heads/main.zip 。

## 可选本地运行与 Agent

网页本地预览：

```sh
python3 -m http.server 8080 --directory dist
```

访问 `http://localhost:8080`，不要双击 HTML 运行模块。

CLI 渲染需要 Python 3、ffmpeg 和 ffprobe；网页公开版不需要这些安装步骤：

```sh
python3 tools/agent.py clip1.mp4 clip2.mp4 --output output.mp4 --ratio 16:9 --seconds 3
```

默认是本地规则规划，输出 H.264/AAC MP4 与 SRT、plan、agent 检查文件，不覆盖已有输出。检查媒体结构不代表理解剧情或验证创意质量。

个人 Skill 在 `skills/edit-video`，API 说明见 `skills/edit-video/references/api.md`，工具契约在 `tools/agent-tools.json`。它们是本地集成说明，不是已运行的独立后台多 Agent 服务。私有后端仍默认 `ALLOW_MODEL_CALLS=0`，公开网页不会接收模型密钥或自动转用付费接口。
