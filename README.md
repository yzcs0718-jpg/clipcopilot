# ClipPilot · 个人视频工作台

**公开网站：https://yzcs0718-jpg.github.io/clipcopilot/**

多素材混剪、参考视频拉片与剪映复现教学。公开版可在浏览器运行免费开源模型，不需安装软件、填写 API Key 或调用付费推理 API。分析结果包含实测证据、复现候选和未确定项，不能承诺任意视频所有效果的准确识别或原工程还原。

## 使用

1. **剪辑创作**：导入一个或多个视频，生成规则混剪初稿，修改片段与自己的文案，预览并导出 MP4。默认不添加无关字幕。
2. **剪映拉片**：选择参考视频后自动运行三步：镜头抽帧 → 中文字幕与动画轨迹 → 窗口几何、人物分割与文字/目标同动分析。上传区实时显示每步进度与失败原因；独立步骤失败时继续其余检查，用户停止则不再启动后续步骤。也可点 **仅快速分镜** 跳过模型，或 **重新完整分析** 重试。首次需要下载免费运行组件和模型，视频采样留在当前浏览器。
3. **复现教学**：展开整片清单中的证据与时间点，核对原片。点击某项的 **生成本项教学 MP4**，生成针对这条线索的参考帧和字幕步骤视频。

没有素材可点 **测试中文花字与圆形窗口** 或 **测试单帧闪白**。人物模型另有独立自检，结果不会冒充上传视频的分析。

### 检查范围与限制

- 视频最长 10 分钟；精细扫描目标约 24fps，最多 3600 帧，长片降低密度并显示实际间隔。可停止重扫并保留上次完整结果。
- OCR 最多 240 个时间点，候选分段边界附近加密。花字、遮挡、透视、小字和短动画可能漏掉或识别错。
- 空间分析最多 90 帧，长视频采样稀疏，跟随关系可能无法判断。矩形检测仅支持完整、未旋转、周围近纯色的窗口，需至少三帧及两次内部纹理变化；复杂背景、静态内容、贴边、任意形状/旋转/羽化仍可能漏检。
- 当前人物遮罩要求可见脸部并通过校验；背影、遮脸、远景、多人、精细头发以及非人物主体不保证可用。
- 成片无法唯一反推出原字体、插件、LUT、变速曲线、蒙版、抠像参数或隐藏背景。同动、圆形边界和人物分割本身都不是原编辑方法的证明。
- 作品链接只记录来源，不会自动同步整账号或批量下载平台视频。

## 验证记录

当前 224 项 JS 回归测试通过，测试数不代表识别准确率。实际 Chrome 测试包含：

- 同一中文字图：此前 Tesseract 失败，现 PaddleOCR 正确读出“剪辑节奏”和英文。
- 原创 6 秒 MP4：六个采样点正确读出描边、彩色、阴影样式下的同一中文文案，获得移动轨迹。
- 同片圆形窗口：实测中心约 81%/58%、直径约占宽 22%；与生成参数接近。
- 同片找到 0.50–5.50 秒文字与独立局部特征的同动候选；加入独立校验后，几何负例不再生成“人物”遮罩。
- 官方公开肖像独立自检生成实际人物遮罩；不作为任意视频抠像准确率证明。
- 单帧白闪：6fps 扫描漏检，24fps 扫描捕获，时间括区约 1.04–1.13 秒。
- 单项圆形窗口教学实际导出、独立解码：17 秒、960×540 MP4。当前测试浏览器编码为 VP9，没有音轨，不代表所有剪辑软件都支持该编码。

- 新增原创 10 秒矩形正反例：Chrome 实测仅得到 4.25–7.75 秒一个矩形动态窗口候选，中心 70%/51%、宽 30%、高 44%；纯色卡片与静态纹理不升级为动态窗口。修复条纹误报圆形及同帧重复计数；原圆形样片仍保留一个圆形候选。
- 单项矩形教学实导出并解码：26.001 秒、960×540、VP9/MP4，无音轨；帧检查确认实测参数与步骤正确。

## 可选本地运行与 Agent

网页本地预览：

```sh
python3 -m http.server 8080 --directory dist
```

访问 `http://localhost:8080`，不要双击 HTML 运行模块。

CLI 渲染需要 Python 3、ffmpeg 和 ffprobe；网页公开版不需要这些安装步骤：

```sh
python3 tools/agent.py clip1.mp4 clip2.mp4 --output output.mp4 --ratio 16:9 --seconds 3
```

默认是本地规则规划，输出 H.264/AAC MP4 与 SRT、plan、agent 检查文件，不覆盖已有输出。检查媒体结构不代表理解剧情或验证创意质量。

个人 Skill 在 `skills/edit-video`，API 说明见 `skills/edit-video/references/api.md`，工具契约在 `tools/agent-tools.json`。它们是本地集成说明，不是已运行的独立后台多 Agent 服务。私有后端仍默认 `ALLOW_MODEL_CALLS=0`，公开网页不会接收模型密钥或自动转用付费接口。

最新跟踪补强：新增原创 8 秒样片（前 2 秒空背景），实际 Chrome 深度拉片得到 2.25–7.75 秒可靠局部轨迹、2.50–7.50 秒“剪辑节奏”与独立目标同动。开头无目标不会阻止后续选点。入口在“更多验证视频”。三个新增回归场景覆盖晚出现、相似物体误匹配、遮挡/尺寸变化/长采样间隔断轨。这些是限定样例验证，不是任意视频跟踪准确率。

### 最新证据核对优化（本地验收）

空间结果不再截取前十张：按每页八帧显示全部实际采样，支持只看边界/可靠人物。放大查看器可翻看相邻采样、切换测量标记、对照新计算的人物遮罩，并将原片暂停在该采样时间。空间缩图仍用于检测；另保留原视频同一时刻的较清晰画面，长边最多960像素，仅用于显示。OCR 框直接来自对应 OCR 输入，不混用邻近时间点的框。

本地 Chrome 实测：矩形样片20帧共3页，末页9.75秒空白帧可见；4.25秒放大图640×360（检测240×135）；切到4.75秒定位后播放器时间4.75、paused=true；圆形/中文深度分析回归通过，隐藏标记状态跨采样保留，人物空筛选可恢复。这里只浏览已采样画面，不能据此宣称逐视频帧覆盖或全部效果识别。

### 字幕往返与缩放精查

旧版只比较首尾文字框，首尾相同会漏掉中途动画。现在比较所有 OCR 观察，按文字框中心衡量移动，独立检查宽度变化，并用最多12个节点近似轨迹。只在中心缩放时不再仅因框左上角移动就误报平移。精查入口在画面文字区，可选最多10秒、约6fps；选区外已有证据保留，每帧记住实际密度，累计最多240帧，重新基础识别可清除精查历史。只有局部精查时，报告明确区间外未知。

原创4秒往返/缩放字幕实测：基础4个采样已识别往返与先大后小；精查24帧均读出“剪辑节奏”，得到一条0.08–3.92秒轨迹和9个试做节点。首节点中心约31%/48%、缩放100%，中途约65%/48%、147%，末节点约33%/48%、104%；这属于可见框的复现建议，不是原字号/曲线/预设还原。字幕卡片可单独导出教学；带明确时间的步骤按该时间选择参考帧并标出真实参考帧时刻。

此改进不解决任意花字、旋转、透明度、复杂蒙版或精细抠像的全部识别。测试数不代表真实视频准确率。

上传流程修复（2026-10-27）：已用真实文件选择器导入原创 6 秒中文花字/圆形窗口样片，自动完成 145 帧镜头采样、6 帧 OCR 和 12 帧空间分析，整片清单直接显示文字、圆形窗口及文字/目标同动三类线索与剪映试做步骤。再次选择相同文件仍会触发完整流程。首次下载及本机推理可能较慢，请查看逐步状态；不调用付费 API。声音分类及转录仍为明确标示的独立可选功能。停止/失败策略有自动回归测试，不代表所有媒体格式均已验证。

剪映做法入口：顶部导航点击 **剪映做法**，或在拉片结果顶部查看 **剪映里怎么做**。按实际线索和时间点排列操作卡片，支持跳到具体效果、播放原片核对、复制步骤及生成本项教学 MP4。复制权限未响应时显示可选中的文本，不会一直等待；未识别的效果不编造步骤。教学仍是参考画面配字幕的示意视频。


三项继续优化（2026-10-27）：
- **减少重复等待**：同一页面、同一参考视频的镜头采样及已完成文字/空间证据可直接复用；失败项继续运行。换视频清空，重新完整分析强制重算。不是首次分析加速承诺，也不是跨刷新持久缓存。
- **短效果局部精查**：选取最多4秒，以60/120次每秒寻帧、最多480帧检查短白闪与静止线索；仅保留最近一次精查，结果加入剪映做法、报告及教学参考帧，不改变全片切点。源帧率和浏览器解码仍限制精度。
- **原片/复现示意对比**：剪映做法卡片可打开同步视频与画布，播放或拖动时间核对。支持白闪、淡入/淡出、整体缩放、定格和字幕几何轨迹；字幕使用中性背景，其他效果使用固定参考底帧，均非剪映渲染，蒙版/人物/跟踪的完整复现尚不支持。

实际Chrome验证：原创60fps单帧白闪样片中，普通25帧采样未检出，局部121帧检出0.517–0.542秒候选；对比在0.529秒左右两侧同时闪白。已验证局部停止后恢复上传、重试成功，及普通采样复用。文字/空间缓存策略另有单元回归，未作运行速度百分比或全视频准确率承诺。样片生成脚本位于tools/make_short60_fixture.sh，不将脚本真值传给检测器。


首次可用结果优化（2026-10-28）：默认基础采样选6次/秒，可切换24次/秒；较稀采样可能漏掉短效果，需局部精查。模型检查默认每项45秒总时限，另可选5分钟；超时中止实际Worker及等待，保留其他已完成结果并继续独立检查，不把不完整结果当成功。基础分镜先展示，模型运行时可导航到已完成的剪映步骤；进度显示已用秒数与上限，上传区和结果区均可跳过当前模型。
实际Chrome样片：文字运行到8/12帧时仍可进入剪映做法并查看已有3项线索；主动跳过后，空间检查继续并成功，最终明确2/3项完成。时限机制有定时回归，未宣称整片45秒内完成或所有效果识别准确。


文字检查续查（2026-10-28）：基础OCR中途停止、跳过或超时时保留成功采样的文字/位置证据和进度，标明完成n/m个计划采样点，未完成的时间仍未知。结果顶部可点“继续未完成检查”，或文字区的“继续文字识别”；只有同一视频、同一采样计划才跳过已完成帧，换视频或变更计划不会误用。进度仅在当前页面内存中，刷新即清除。已有完整检查时，失败的新尝试不会覆盖原完整结果。空间检查和局部字幕精查目前仍不支持这种逐帧续查。

### 自动补查短效果

默认启用，可取消勾选“自动补查短效果”。基础分镜先显示，随后4秒内的视频按最多120次/秒寻帧补查全段；更长视频按实测像素变化选择最多6处不重叠切点窗口，每处约0.7秒、60次/秒。额外总预算不超过480帧。补查约12秒计算窗口后不再启动新采样，正在等待的单次解码可能延长实际时间；停止或出错时仅采用已完成窗口，不采用半途窗口，基础结果保留。

每个补查窗口独立检查白闪、黑闪与定格，不把稀疏和密集采样混成一个网格；保留跨出窗口的长定格证据。检测结果自动进入整片剪映教程、镜头卡片、参考帧、报告和教学数据。手动精查仍可继续；改变自动补查开关会重算分镜与补查。尚不支持自动检查任意字幕、蒙版和插件短效果。

实际Chrome验证：原创1秒60fps单帧白闪视频，在默认6次/秒基础采样（7帧）后自动补查121帧，发现约0.517–0.542秒白闪候选并直接显示剪映步骤，无需点击手动精查。此为已知样片的回归证据，不代表任意视频识别准确率。寻帧次数不等于源帧率。


### 画面平移与彩色闪帧

- **整体横移 / 纵移候选**：在候选镜头中比较五个采样位置，检查纹理对齐、匹配改善和方向连续性；显示相对画面宽高的位移比例、五个位置关键帧试做节点。排除纯色、静态、明显往返、场景切换和测试中的局部主体移动；仍可能来自实拍摇移或平面主体运动，不能确认原作者使用关键帧。位移搜索限于低清帧宽高的约20%，复杂视差和强模糊可能漏检。
- **彩色闪帧候选**：检测短暂、近全屏的高饱和纯色画面，检查前后画面相似性；显示实测十六进制颜色及上层纯色素材、不透明度的剪映步骤。不是任意漏光、混合模式或彩色转场识别。自动补查和手动精查均采用该检测。

### 非转场能力：整体震动与去色/恢复彩色

- 整体抖动/震动候选：在最多17个测量节点拟合相对首帧的整体平移，要求至少3次主方向改变、足够行程和较低对齐残差。候选段外另补最多4个跨候选切点窗口，防止像素误切使抖动漏检。转折处有重复测量位置时仍保留换向节点。输出时间、宽高位移百分比、剪映位置关键帧步骤和固定参考帧对比。相机晃动或平面主体也可能满足条件；细微/高频抖动、模糊和新露出的边缘内容不能准确恢复，预览可能露黑。
- 彩色逐渐变黑白/黑白恢复彩色候选：对7个节点的亮度结构和色彩分量做比例拟合，检查单向去色/恢复；同时按亮度结构稳定区间检查漏切长段，允许舍弃一个边界污染采样。输出相对色彩强度、饱和度试做步骤、版本不支持调节关键帧时的同片段双层不透明度方案，以及固定彩色参考帧的去色对比。测量百分比不等于剪映滑块值；不反推LUT、滤镜或真实原色。
